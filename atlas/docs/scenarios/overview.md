# Scenarios

The Atlas separates implemented exercises from proposed operator flows so that a reader can tell what the current repository can run.

| Scenario | Current status |
| --- | --- |
| [Commissioning](commissioning.md) | Documented exercise using the current SHIRE ground and flight interfaces |
| [Nominal Operations](nominal-operations.md) | Proposed operator flow built from implemented capabilities |
| [Fault Detection, Isolation, and Recovery](fdir.md) | Implemented exercise for the Demo component using LC, SC, and an RTS |
| [Security Incident Response](security-incident-response.md) | Proposed exercise using the current radio, CryptoLib, and ground links |

Before running a scenario, select the mission, spacecraft, and scenario as described in [Configuration](../manual/how-to/configuration.md), then build the generated configuration.

Questions and improvement ideas are welcome in [GitHub Discussions](https://github.com/VoyagerTechnologies-Public/shire/discussions).
Report reproducible defects through [GitHub Issues](https://github.com/VoyagerTechnologies-Public/shire/issues).
